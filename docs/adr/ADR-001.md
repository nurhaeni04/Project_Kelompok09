# ADR-001: Pemisahan Database Setiap Microservice


## Status

Accepted


## Konteks

Sistem War Tiket Konser menggunakan pendekatan microservices yang terdiri dari beberapa layanan yaitu event-service, ticket-service, payment-service, dan notification-service.

Setiap layanan memiliki tanggung jawab berbeda sehingga membutuhkan pengelolaan data yang terpisah.

Selain itu, proses pembelian tiket memiliki sumber daya yang bersifat rebutan yaitu kursi konser. Pengelolaan kursi harus dilakukan oleh ticket-service agar tidak terjadi konflik data.


## Keputusan

Setiap microservice memiliki database dan pengelolaan data sendiri.

Pembagian tanggung jawab:

- event-service mengelola data konser.
- ticket-service mengelola data tiket dan kursi.
- payment-service mengelola transaksi pembayaran.
- notification-service mengelola data notifikasi.

Service lain tidak diperbolehkan mengakses database service lain secara langsung. Komunikasi dilakukan melalui API.


## Konsekuensi

### Keuntungan:

- Setiap service dapat dikembangkan secara independen.
- Sistem lebih mudah diskalakan ketika jumlah pengguna meningkat.
- Risiko gangguan pada satu service tidak langsung mempengaruhi service lain.


### Kekurangan:

- Komunikasi antar service menjadi lebih kompleks.
- Membutuhkan pengaturan API dan event antar layanan.
